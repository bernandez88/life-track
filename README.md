# life-track

API privada para organizar gastos, ejercicios, actividades y notas. Está preparada para ejecutarse en Cloudflare Workers con D1.

## Desarrollo

```bash
npm install
npm run check
npm test
npm run dev
```

Consulta [CLOUDFLARE.md](CLOUDFLARE.md) para autenticación, migraciones, secretos, GitHub Actions y MCP.
